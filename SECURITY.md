# Security policy

Please report suspected vulnerabilities privately through [GitHub Security
Advisories](https://github.com/Idriz-hax/harbor-ledger-memory/security/advisories/new).
Do not disclose exploitable details in a public issue or pull request.

Include enough information to reproduce the issue, its potential impact, and
any suggested mitigation. The maintainers will review reports through GitHub;
this project does not promise a specific response or resolution time.
